Guardar cambios

  1. Pulsa Descargar archivos. Se descargarán los archivos que han cambiado: .
  2. En tu repositorio de GitHub, abre la carpeta data y elige Add file → Upload files.
  3. Arrastra los archivos descargados, que sustituirán a los anteriores, y pulsa Commit changes.
  4. Espera uno o dos minutos a que GitHub Pages publique el cambio.
